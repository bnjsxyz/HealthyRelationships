# Healthy Relationships Quest

Self-paced Grade 11 Life and Career Skills HTML lesson and quiz, based on the supplied textbook excerpts and classroom synthesis. Visual design and learner check-in are inspired by the provided `Practice.html` reference.

## Deploy on GitHub Pages
1. Create a public GitHub repository (or use an existing repository).
2. Upload `index.html`, `README.md`, and `.nojekyll` to the repository root.
3. Open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, choose **main** and **/(root)**, then Save.
4. Open the GitHub Pages URL after deployment completes.

## Features
- Self-contained HTML, CSS, and JavaScript; no external dependencies.
- Grade 11 learner check-in (name and section), 11 learning sections, two interactive checkpoints, and 12-item mastery check.
- Correct answers and explanations for the mastery check appear only after submission.
- Locally saved progress, learner record, and quiz answers.
- Printable completion certificate and downloadable text result.
- Responsive layout with keyboard-accessible buttons and radio controls.

## Important limitations
- GitHub Pages is static hosting. The teacher cannot automatically collect results, verify learner identity, or enforce one attempt across browsers/devices.
- Local storage can be cleared, changed, or unavailable in private browsing. Certificate and result files are locally generated and not authenticated.
- Do not treat this as a secure proctored assessment. For verified collection, use an approved school platform or a server-backed service.

## Local preview
Open `index.html` directly in a browser. For iOS, GitHub Pages is preferable to an Apple Files preview, which may restrict scripts.

## Editing
All lesson content, quiz questions, styles, and JavaScript are in `index.html`. Keep the filename `index.html` for GitHub Pages.
